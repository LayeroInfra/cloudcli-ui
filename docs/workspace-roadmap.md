## Фаза A — автономная разработка Workspace (сейчас)

Цель: агент проводит задачу по самому Workspace — ветка, проверки, стенд,
снимок экрана и e2e, PR, слияние, выкатка — без человека на каждом шаге.
Метрика — сколько раз за задачу агент упёрся в человека. База — сессия этапа 0,
около 12 раз (таблица ниже).

## Фазы брифа после A

1. Модель данных Workspace: своя история сообщений, проект ≠ путь, память вне
   каталогов провайдера, права доступа (common/private, доступ к чату).
2. Командная работа: «Требует ответа», автор у сообщения, несколько аккаунтов
   агентов, GitHub в профиле.
3. Снимки в S3 и перенос на новую VM.
4. «Процессы» и ресурсы, манифест проекта (частично закрыты A2, A9).
5. Приложение и браузер: Mac-доводка, релизы Companion, браузер для агента (после A6).
6. Мобильный доступ.
